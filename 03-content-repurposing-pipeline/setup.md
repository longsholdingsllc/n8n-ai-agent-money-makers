# Content Repurposing Pipeline – Setup Guide

## What it does
Takes a long-form piece (blog URL, Notion page, or raw text) and generates platform-optimized versions: LinkedIn post, X thread, email newsletter section, and short-form script. Optionally schedules via Buffer or native APIs.

## Value to client
Turns one piece of content into 5–10 distribution assets in minutes instead of hours.

## Suggested pricing
- One-time build: $797–$1,997
- Digital product: $69

## Import & Configure
1. Import workflow.
2. Set LLM credentials.
3. Update prompts for brand voice.
4. Connect output destinations (Google Docs, Buffer, Notion, etc.).
